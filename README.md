# Módulo — Introdução à Orientação a Objetos

Atividade prática do curso **EBAC Back-end Java v2** para exercitar a criação de classes e objetos em um pequeno programa de cadastro de veículos.

## O que o programa faz

- Pergunta quantos veículos serão cadastrados, com limite de 50.
- Recebe o nome e o preço de cada veículo.
- Armazena os dados em objetos `Carro`, organizados em um array.
- Exibe os nomes cadastrados, a quantidade de veículos e a soma dos preços.

## Conceitos praticados

- Classes e objetos (`Carro`).
- Atributos de instância.
- Arrays de objetos.
- Laços `while` e `for`.
- Entrada de dados com `Scanner`.
- Acumulador para calcular o valor total.

## Como executar

Abra o projeto no IntelliJ IDEA e execute `src/Main.java).

## Limitações

É um exercício introdutório de terminal. Os dados ficam na memória durante a execução; não há banco de dados ou gravação em arquivo. A validação de entrada é básica.
